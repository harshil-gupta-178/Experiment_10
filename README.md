# Experiment 10: Cloud Website Deployment

Deploy a static website on Netlify / GitHub Pages and a dynamic website on Heroku or AWS.

## Part 1: Static Website (GitHub Pages / Netlify)
- **Live Demo**: [https://harshil-gupta-178.github.io/Experiment_10/](https://harshil-gupta-178.github.io/Experiment_10/)
- Built with HTML5, CSS3, and JavaScript.
- Topic: Introduction to Cloud Computing, Service Models (IaaS, PaaS, SaaS), and Deployment Models.

## Part 2: Dynamic Website (Heroku / AWS)
Located in the `dynamic-website/` folder.
- Built with Node.js and Express.
- Provides server-side runtime, live server metrics, and a dynamic REST API.

### Run Locally:
```bash
cd dynamic-website
node server.js
```
Open `http://localhost:3000` in your browser.

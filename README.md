# Experiment 10: Cloud Website Deployment

A simple static website about Cloud Computing, built with HTML, CSS, and JavaScript.

- **Live Demo:** https://harshil-gupta-178.github.io/Experiment_10/

## Branches
- **`main`** — Static website (ready for **Netlify** or **GitHub Pages**).
- **`dynamic`** — Node.js & Express app (ready for **Heroku** or **AWS**).

## Run Locally
Open `index.html` directly in your browser.

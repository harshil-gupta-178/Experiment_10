Introduction to Cloud Computing

Cloud computing is the on-demand delivery of computing services including servers, storage, databases, networking, software, and analytics over the internet.

What is Cloud Computing?

Instead of purchasing and maintaining physical servers and data centers, organizations can access technology services on an as-needed basis from a cloud provider such as AWS, Microsoft Azure, or Google Cloud.

Cloud Service Models

IaaS (Infrastructure as a Service)

Provides basic computing infrastructure: virtual machines, physical servers, storage, and networking. The user manages the operating system, runtime, and applications.

Examples: Amazon EC2, Google Compute Engine, Microsoft Azure Virtual Machines

PaaS (Platform as a Service)

Provides a managed hardware and software platform so developers can build and run applications without managing underlying infrastructure or operating systems.

Examples: Heroku, AWS Elastic Beanstalk, Google App Engine, Netlify

SaaS (Software as a Service)

Delivers complete software applications over the internet on a subscription basis. Infrastructure, runtime, and software maintenance are entirely managed by the provider.

Examples: Google Workspace, Microsoft 365, Dropbox, Salesforce

Cloud Deployment Models

Public Cloud

Cloud infrastructure delivered over the internet and shared across multiple organizations by a third-party provider.

Private Cloud

Cloud infrastructure dedicated exclusively to a single organization, hosted either on-premises or by a third party.

Hybrid Cloud

An integrated environment connecting private and public cloud infrastructures to share data and applications.

Key Benefits of Cloud Computing

  • Cost Efficiency: Eliminates upfront capital expense of hardware and facilities.
  • Scalability: Resources can scale dynamically based on demand.
  • Performance: Data centers located globally ensure reliable network performance.
  • Reliability: Data backup, disaster recovery, and business continuity are simplified.
